# Beat Packs

Un jeu de packs de cartes musique, inspiré des packs FIFA Ultimate Team.

## Lancer le jeu
Ouvre `index.html` dans ton navigateur (ou utilise l'extension Live Server dans VS Code).

## Fichiers
- `index.html` : la structure de la page
- `style.css` : les couleurs, les cartes et les packs
- `script.js` : la liste des artistes, l'ouverture des packs et la collection

## Idées pour la suite
- Cartes « titre » et cartes spéciales
- Mode festival (équipe de 5 artistes)
- Matchs contre l'ordinateur
